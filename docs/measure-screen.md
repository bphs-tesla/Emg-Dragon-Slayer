# 측정 화면 설명

참가자마다 근육 힘의 최저값과 최고값을 재는 화면이다. 이 두 값을 기준으로 이후 목표 레벨 구간(%)을 계산한다.
코드: 화면은 `pscgame/ui.py`의 `_measure`, 동작은 `pscgame/game.py`의 `_start_measure`·`_measure_window`, 계산은 `pscgame/calibration.py`.

## 흐름

```
TITLE ─Space→ 최저 측정(MEASURE_MIN) ─완료→ 최고 측정(MEASURE_MAX) ─성공→ ROULETTE
                      ↑                              │
                      └──────── 범위 부족(실패) ───────┘
```

1. 타이틀 화면에서 `Space`를 누르면 **힘 측정 1/2**(최저값)가 시작된다.
2. 최저값 측정이 끝나면 곧바로 **힘 측정 2/2**(최고값)로 넘어간다.
3. 최고값까지 끝나고 두 값의 차이가 충분하면 룰렛 화면으로 간다.

두 단계는 같은 화면을 쓰고 제목만 다르다.

| 단계 | 상단 HUD 제목 | 패널 제목 | 참가자가 할 일 |
|---|---|---|---|
| `MEASURE_MIN` | 힘 측정 1/2 · 힘 빼기 | 힘을 빼세요 | 근육 힘을 완전히 뺀다 |
| `MEASURE_MAX` | 힘 측정 2/2 · 최대 힘 | 최대한 힘을 주세요! | 낼 수 있는 최대 힘을 준다 |

## 화면 구성

가운데 700×300 패널에 위에서부터 다음을 그린다.

1. **제목**: 위 표의 패널 제목 (큰 글씨, 흰색)
2. **오류 메시지**: 직전 측정이 실패했을 때만 빨간 글씨로 표시 (아래 "실패와 재측정" 참고)
3. 그 아래는 진행 상태에 따라 둘 중 하나:
   - **카운트다운 중**: 아주 큰 노란 숫자 `3 → 2 → 1`
   - **측정 중**:
     - 진행 막대: 모은 값 개수 ÷ 필요한 개수만큼 분홍색으로 채워진다
     - "측정 중..." 문구
     - `현재 12.3`: 가장 최근에 받은 센서 값 (작은 회색 글씨, 값을 한 번이라도 받은 뒤에만)

## 측정 방식

- 각 단계는 **카운트다운 3초 → 측정 3초**로 진행된다 (`countdown_seconds`, `calib_seconds`).
- 센서 값은 0.2초 창(`window_seconds`) 단위로 하나씩 들어온다. 그래서 3초 측정이면 값 15개를 모은다.
- 카운트다운 동안 들어온 값은 버린다.
- 값이 비어 있는 창(그 0.2초 동안 샘플이 없음)은 개수에 넣지 않는다.

계산식:

- **최저값** = 모은 값 15개의 평균
- **최고값** = 모은 값 중 **상위 5개의 평균** (`max_top_n`). 잡음이 한 번 튄 값이 최고값이 되는 것을 막는다.

## 실패와 재측정

| 상황 | 표시되는 메시지 | 이후 동작 |
|---|---|---|
| 측정 중 값이 0.6초(창 3개) 연속 비어 있음 (`signal_loss_seconds`) | 신호 끊김, 다시 측정합니다 | **지금 단계**를 카운트다운부터 다시 |
| 최고값 − 최저값 < `min_range`(기본 5.0) | 측정 실패, 다시 측정합니다 | **최저값 측정(1/2)**부터 다시 |

- 오류 메시지는 다음 측정이 성공할 때까지 화면에 남는다.
- 재측정할 때는 그 단계에서 모은 값을 모두 버리고 처음부터 모은다.

## 키 입력

- 측정 화면에서는 `Esc`(타이틀로)와 `Ctrl+Q`(종료)만 동작한다. `Space` 등 다른 키는 무시한다.
- 측정을 마친 뒤 룰렛 화면에서 `R`을 누르면 최저값 측정부터 다시 할 수 있다.

## 관련 설정 (`pscgame/config.py`)

| 이름 | 기본값 | 의미 |
|---|---|---|
| `countdown_seconds` | 3 | 측정 전 카운트다운 (초) |
| `calib_seconds` | 3.0 | 측정 시간 (초) |
| `window_seconds` | 0.2 | 값 하나를 만드는 창 길이 (초) |
| `max_top_n` | 5 | 최고값 계산에 쓰는 상위 값 개수 |
| `min_range` | 5.0 | 최고값과 최저값의 최소 차이 (센서 원값 단위) |
| `signal_loss_seconds` | 0.6 | 이만큼 값이 없으면 신호 끊김으로 처리 (초) |
